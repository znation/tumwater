**Goal.** `startPostReview` (src/merge/merge-post-review-drain.ts, called from `drainPostReviews`) answers two separate reader questions in one `run` IIFE: whether a parked review is admitted to run at all, and how the review's verdict settles the entry. The admission is a short prelude (acquire the team permit at VERIFY_TIER; when the lease is null, the abort signal fired, `ctx.startHeld()` is true, or the entry is no longer unreviewed, release the permit and return without running the reviewer). The verdict settlement is a six-way `outcome.kind` ladder — `approve` → `settlePostReview(null)`, `reject` → settle with `rejected`, `fixed` → `mergeReviewerFix`, `exhausted` → `settlePostReview(null)`, `failed` with `infrastructure` → warn and keep queued (no count, no file), `failed` otherwise → warn, count `failures`, and either file-and-drop at `POST_REVIEW_FAILURE_LIMIT` or settle with the count. Each arm reads the same `task`, `lease`, `entry`, `root` and `ctx` locals, so the two concerns are welded into one body. Lifting each into one named module-private helper lets a name answer each question while the `run` IIFE becomes an ordered sequence of those names plus the `try/catch/finally` scaffolding. This is a behavior-preserving extraction only.

**Approach.** All edits are inside the `run = (async () => { … })()` IIFE in `startPostReview`'s body in src/merge/merge-post-review-drain.ts; nothing else in the file, and no other file, changes.
- Add two module-private helpers, both taking the locals they read so the IIFE keeps computing them once:
  - `admitPostReview(root, lease, task, ctx, entry)` (module-private): lift the current post-lease prelude verbatim — set `task.parked = false`; if `lease === null` return false (a shutdown while parked leaves the entry for the next generation); compute `stale = task.controller.signal.aborted || ctx.startHeld() || !readPostReviews(root).some((e) => e.commit === entry.commit && unreviewed(e))`; if `stale` release the lease and return false; otherwise return true. The IIFE stays responsible for acquiring the lease and for releasing it in the `finally`-path already it owns (a `return` from `admitPostReview` returns from the IIFE, so the IIFE's existing `try/finally` cleanup — `detach()` and the `p.postReview` slot clear — still runs).
  - `settlePostReviewOutcome(ctx, entry, outcome, author)` (module-private, `Promise<void>`): lift the current `if (task.controller.signal.aborted) return;` post-run guard plus the entire `outcome.kind` if/else-if ladder verbatim into one function, replacing the `task.controller.signal.aborted` read with a passed `aborted: boolean` argument (the IIFE computes `task.controller.signal.aborted` once, at the point the ladder currently reads it) and the `entry.failures`/`shortSha` reads with its own locals; every `settlePostReview`/`mergeReviewerFix`/`fileDroppedReview`/`warnEventBestEffort` call and every warning string moves byte-identical, and the `finally { detach(); if (p.postReview === task) p.postReview = null; }` stays in the IIFE (it references `p` and `task`, which are `startPostReview`'s own locals, not the outcome's).
- Rewrite the IIFE body to: acquire the lease; `if (!await admitPostReview(root, lease, task, ctx, entry)) return;` (the `task.parked = false` set and the lease release in the not-admitted arms move into `admitPostReview`); then the existing `try { outcome = await reviewMergedCommit(…); } finally { lease.release(); }` unchanged; then `await settlePostReviewOutcome(ctx, entry, outcome, author, task.controller.signal.aborted);`. Keep `startPostReview`'s signature `(ctx, p, entry): void` and its single call site in `drainPostReviews` unchanged; keep both new helpers module-private (non-exported). Do not change `drainPostReviews`, `mergeReviewerFix`, `fileDroppedReview`, `resolveAuthor`, or any string they build.
