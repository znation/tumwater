### Every commit is verified on main: the deterministic gates run on each new tip, and nothing blocks a landing (decided by the user 2026-10-24; requires "Forward, never back" landed — with the pre-merge model verdict gone a finding has one home, the reviewer's post-landing pass; supersedes the merge-run and bisect halves of plans/fast-merge.md "What stays" and plans/review-gate.md's pre-merge verdict)

**Goal.** A commit is never stopped on its way to main. What verifies main is a deterministic check on the commit that just landed — lint, compile and the project's declared check command, plus the conflict-marker, protected-edit, secret-leak and backlog-structure rules — run against main's new tip on every poll, and then the reviewer's post-landing pass. With the check running on every new tip, the tip *is* the culprit.
