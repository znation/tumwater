**Goal.** `pushDigestHeader` (src/failure/failure-render.ts, called first from `renderFailureMarkdown`) answers two separate reader questions in one body: how the digest names its window, and what it says about the evidence. The window line is a 3-way ternary (bounded `--since/--until` span vs. trailing `--since` vs. calendar day) and the evidence-state lines are a 4-way `if/else if` ladder (a present-but-unreadable feed, an empty log, an out-of-span window, a partial log) — and both read the same local `bounded` const, so the two concerns are welded to one line of shared state. Lifting each into one named module-private helper that takes `bounded` as an argument lets a name answer each question while keeping the shared const computed exactly once in `pushDigestHeader`. This is a behavior-preserving extraction only.

**Approach.** All edits are inside `pushDigestHeader`'s body in src/failure/failure-render.ts; nothing else in the file, and no other file, changes.
- Add two module-private helpers, each taking the shared `bounded: boolean` as a parameter so the const stays computed once by the caller: `digestWindowLine(data: FailureReportData, bounded: boolean): string` (lift the current window-line ternary verbatim — `bounded ? trailingWindowLine(data.sinceMs!, data.fromIso!, data.untilMs, data.toIso) : data.sinceMs !== undefined ? trailingWindowLine(data.sinceMs, data.fromIso!) : reportWindow(data.from, data.to, data.days, eventsRotationLabel())` — and return that phrase with the same ` · ${data.runs} runs` suffix the three branches share) and `digestEvidenceLines(data: FailureReportData, bounded: boolean): string[]` (lift the current `if (data.logState === "unreadable") / else if (data.emptyLog) / else if (!data.hasEvents) / else if (data.partial)` ladder verbatim into an array: one string each for the reachable arm, empty when none fires; the `!data.hasEvents` arm keeps reading `bounded` for its since-vs-day "no events …" phrasing).
- Rewrite `pushDigestHeader` to compute the `bounded` const once (unchanged) and then: push the title `"# tumwater failure digest"`, push the blank line, push `digestWindowLine(data, bounded)`, keep the `if (data.role !== undefined) lines.push(\`role: ${data.role}\`)` line inline (it is a single guard, not a ladder — leave it where it is), and `lines.push(...digestEvidenceLines(data, bounded))`. Keep its signature `(lines: string[], data: FailureReportData): void` and its single call site in `renderFailureMarkdown` unchanged.
- Do not change `renderFailureMarkdown`, any other `push*` section helper, the leaf helpers (`trailingWindowLine`, `reportWindow`, `durationLabel`, `dayLabel`, `eventsRotationLabel`), or any string they build. Keep both new helpers module-private (non-exported).
